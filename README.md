# NZ SDET — учебный репозиторий

Здесь хранятся контракты заданий, решения ученика и проверяемые результаты практики Python → SDET. Это **не** production framework и не показатель готовности к найму по количеству PR.

## Для нового AI-агента: начни только с двух файлов

1. **[AGENTS.md](AGENTS.md)** — **единственная актуальная инструкция** о поведении, манере преподавания, ревью, GitHub, отчётах и восстановлении после сбоя.
2. **[PROJECT_STATE.md](PROJECT_STATE.md)** — сегодняшняя точка, законченные задачи, действующие ограничения и необходимость воздержаться от заданий до запроса ученика.

При выборе новой темы дополнительно прочитать [ROADMAP.md](ROADMAP.md). Для предметного ревью/отчёта — релевантные записи [LEARNING_LOG.md](LEARNING_LOG.md), исходный `task_NN.md`, соответствующий PR и доступный чат. **Не читать архив как конкурирующий регламент.**

## Навигация

- [ROADMAP.md](ROADMAP.md) — порядок учебных тем.
- [LEARNING_LOG.md](LEARNING_LOG.md) — хронология проверяемых результатов, ошибок и использованной помощи.
- [docs/ACTIVE_WEEK.json](docs/ACTIVE_WEEK.json) — машинный указатель недели для проверки каталогов контрактов.
- [docs/HISTORICAL_CONTRACTS.md](docs/HISTORICAL_CONTRACTS.md) и [docs/REPO_AUDIT.md](docs/REPO_AUDIT.md) — **исторические справки, не инструкции**.
- [reports/](reports/) — обезличенные отчёты; шаблоны в `reports/templates/`.
- `weekXX/documentation/` — условия задач; `weekXX/solutions/` и `weekXX/input_files/` — код и учебные данные.

## Проверки

Из корня репозитория, в окружении с установленным pytest, можно целево запускать, например:

`python -m pytest week03/solutions/test_users.py -v`

Это **пример команды**, а не запись о выполненном сейчас тесте. Не считать общий pytest гарантированно зелёным: некоторые тесты **намеренно выявляют дефекты** учебных исходников. Окружение и зависимости ещё не стандартизированы.

## Публичность и восстановление

Не публикуй архивы личных бесед, персональные медицинские/финансовые сведения, служебные материалы работодателя, токены или секреты. Старые правила и история изменений сохранены в Git; отдельные документы поведения были объединены в `AGENTS.md`, чтобы новый агент не читал конкурирующие инструкции.

**Короткая команда после сбоя:** «Открой AGENTS.md и PROJECT_STATE.md в main через Xoxacc_SDET. Восстанови состояние и не давай заданий без моего запроса».
