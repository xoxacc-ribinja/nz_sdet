# NZ SDET — learning portfolio

Публичный учебный репозиторий: Python Core, тестирование на pytest и дальнейшее развитие навыков SDET. Здесь хранятся задания, решения, небольшие входные наборы данных и проверяемые результаты практики.

**Статус:** задания 01–16 изучались; текущий фокус — закрепление Python Core и pytest. Это учебный журнал, а не готовый production framework. Наличие решения не означает, что в нём нет дефектов.

## Запуск

Из корня клонированного репозитория, в виртуальном окружении с установленным `pytest`:

    python -m pytest week03/solutions/test_users.py -v

Не запускайте все тесты с ожиданием зелёного результата: в Task 14/15 есть тесты, намеренно демонстрирующие дефект исходной функции доставки. Окружение и зависимости ещё не стандартизованы.

## Публичность и безопасность

Не публиковать личные данные, конфиденциальные рабочие материалы, токены, секреты, частные конспекты переписок и полные журналы самочувствия. В отчётах оставлять только технические выводы и обезличенный прогресс.

**Авторство:** учебный код и решения принадлежат владельцу репозитория. Документация процесса может редактироваться при помощи AI; решения учебных заданий оцениваются отдельно по самостоятельной работе.
