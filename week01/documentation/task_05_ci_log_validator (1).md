# Task 05 --- CI Log Validator

## Цель

Прочитать файл `ci_jobs.txt`, отделить корректные записи от некорректных
и построить краткий отчёт по корректным CI jobs.

## Input: `ci_jobs.txt`

``` text
build_windows,PASSED,42
build_linux,FAILED,55
deploy_dev,PASSED,31
broken_line
tests_api,SKIPPED,18
deploy_prod,BROKEN,70
tests_ui,FAILED,95
lint,PASSED
package,PASSED,27
```

Формат корректной строки:

``` text
job_name,status,duration
```

Допустимые статусы:

``` text
PASSED
FAILED
SKIPPED
```

`duration` пока считай корректным, если третье поле присутствует.
Проверять, является ли оно числом, в этой задаче НЕ нужно.

## Что считается некорректной строкой

Строка некорректна, если выполняется хотя бы одно условие:

-   после `split(',')` получилось не ровно 3 поля;
-   status не входит в список допустимых статусов.

Некорректная строка не должна участвовать в статистике jobs.

## Expected output

``` text
Valid jobs: 6
Invalid lines: 3

By status:
PASSED: 3
FAILED: 2
SKIPPED: 1

Invalid input:
- broken_line
- deploy_prod,BROKEN,70
- lint,PASSED
```

## Требования

-   Python.
-   Имя входного файла можно задать константой.
-   Использовать только уже знакомые конструкции: `list`, `dict`, `for`,
    `if/elif/else`, функции, чтение файла, `split`, `len`, `in`.
-   Минимум 3 функции.
-   Нельзя использовать classes, `set`, `Counter`, external libraries.
-   Не хардкодить названия конкретных jobs и итоговые числа.
-   Допустимые statuses можно хранить в константе.
-   Не использовать `try/except` --- исключения будем изучать отдельно.
-   Не нужно проверять, является ли `duration` числом.
-   Не нужно сортировать output.

## PASS criteria

Программа должна:

1.  Не падать на строках неправильного формата.
2.  Не считать `BROKEN` корректным status.
3.  Получить `Valid jobs: 6`.
4.  Получить `Invalid lines: 3`.
5.  Получить PASSED=3, FAILED=2, SKIPPED=1.
6.  Вывести все три исходные некорректные строки.
7.  Корректные строки не должны попадать в `Invalid input`.
8.  Пользователь должен суметь объяснить, почему каждая из трёх
    invalid-строк была отвергнута.

## Ограничение по AI

Можно спрашивать:

-   значение конкретной ошибки Python;
-   синтаксис уже знакомой конструкции;
-   что делает конкретный метод/оператор.

Не просить AI написать функцию или алгоритм решения целиком.

## Рекомендуемый лимит

30--45 минут.

Если через 45 минут решение не готово --- остановиться и показать
текущий код. Это не failure: задача нужна для диагностики, а не для
марафона.
