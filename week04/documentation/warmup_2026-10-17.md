## 1. first_repeat

```python

```

Вернуть **первое значение**, которое встретилось второй раз при проходе списка слева направо.

Примеры:
- `[4, 2, 7, 2, 4] -> 2`
- `[1, 3, 5] -> None`
- `[] -> None`
