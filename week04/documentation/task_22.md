# Task 22 — Соседний дубль шага тестового сценария

**Дата:** 2026-10-15. **Начать реализацию после слияния контракта в main.**

## Цель и новая конструкция
Небольшая Python Core-задача (ориентир 20–35 минут) на цикл, сравнение соседних значений, возвращаемый кортеж и отсутствие мутации. Единственная предлагаемая новая конструкция — `enumerate(iterable)`: она выдаёт пары `(индекс, значение)` с индексом от нуля, например для `['A','B']` получаем `(0,'A')`, `(1,'B')`. Она объяснена в чате до задания. **Использовать её не обязательно:** можно обойтись знакомым `range` или обычным циклом.

## Поведенческий контракт
Реализовать `week04/solutions/python_core_22.py`:

```python
def first_adjacent_duplicate(steps: list[str]) -> tuple[int, str] | None:
    ...
```

- `steps` — последовательность имён шагов автотеста. Входные данные корректны: это всегда `list[str]`. Строки могут быть пустыми `''`; проверять типы и выбрасывать исключения **не требуется**.
- Найти **первую пару соседних** одинаковых строк (`steps[i-1] == steps[i]`). Вернуть кортеж `(i, steps[i])`, где `i` — **индекс второго элемента пары, начиная с нуля**.
- Сравнение **точное, с учётом регистра и пробелов**; `'API'` и `'api'`, как и `'A'` и `'A '`, не равны.
- Если соседней одинаковой пары нет, вернуть `None`. Пустой список и список из одного элемента тоже дают `None`.
- При нескольких соседних повторах выбрать **самую раннюю** пару по индексу второго элемента.
- Нельзя изменять `steps` или печатать результат, нельзя пользоваться глобальным состоянием. Не использовать внешние библиотеки.
- Примеры:
  - `['API','DB','DB','UI']` → `(2, 'DB')`;
  - `['API','DB','API']` → `None` (повтор есть, но **не соседний**);
  - `['','']` → `(1, '')`;
  - `['A','A','A']` → `(1, 'A')`;
  - `['API','api']` → `None`.
