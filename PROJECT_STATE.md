## Учебные правила

- Приоритет тем: около 60% SDET / 40% Python Core.
- Формат работы: около 25% нового материала, 50% повторения, 25% отладки и защиты решений.
- **Новый ориентир с 2026-10-11: 12 часов в неделю** по решению ученика; ранее было 3–5 часов. Это гибкий недельный объём, без обязательного ежедневного расписания и без требования «отрабатывать» пропуски. Не повышать часы автоматически из-за проблем с запоминанием. Время непосредственного кодирования, анализа/ревью и организационных действий отмечать отдельно.
- **Bug Investigation:** регулярный самостоятельный формат: от симптома и traceback к гипотезе, первопричине, минимальному исправлению и запуску тестов. Чтение небольшого незнакомого кода — эпизодически. Недельный тематический фокус не вводить.
- После Task 18 изменён способ практики: меньше почти одинаковых упражнений; больше задач в новом контексте на уже знакомых инструментах, воспроизведения без подсказок и интервального повторения через несколько дней.
- Отдельно отмечать уровень самостоятельности: без подсказок / после наводящего вопроса / после подробного объяснения. Правильность результата и самостоятельность — разные показатели; не менять задним числом критерии PASS.
- Важнее независимое решение и удержание знаний, чем количество закрытых заданий.
- Для проверки самостоятельности используются короткие задачи без AI; документация допустима, если её использование обозначено.
- Не выдавать новые задания и не отмечать PASS без фактической проверки и обсуждения.
- Перед новым заданием публиковать Markdown-контракт в GitHub; критерии PASS не расширять задним числом. Новые конструкции Python сначала объяснять.
- После защиты решений иногда применять скрытые входные данные для дополнительной проверки. Проверять только согласованный контракт, раскрывать конкретные кейсы после проверки и фиксировать реальные результаты (см. `docs/WORKFLOW.md`).
- После первого обращения за день в учебном чате — 3–4 коротких вопроса без написания кода для повторения Python Core, pytest, Git и тест-дизайна. Ответы разбираются в чате; это не отдельная задача на PASS.
