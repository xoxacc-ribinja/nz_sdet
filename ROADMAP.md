# Roadmap: Python → SDET

Дорожная карта по направлениям, без фиктивных сроков и обещаний готовности к найму.

| Направление | Текущее состояние | Следующее проверяемое умение |
| --- | --- | --- |
| Python Core | Практика на обработке данных, функциях и коллекциях; требуется повторение | Решать небольшие задачи без подсказок, находить собственные ошибки |
| pytest | Освоены базовые тесты, `raises`, `parametrize`, простая `fixture` | Самостоятельно проектировать тесты по контракту и объяснять границы |
| Git / code review | Есть история Git и опубликованный репозиторий | Работать через ветки, осмысленные коммиты и PR |
| REST API testing | Впереди | Проверять статус, тело, схему и негативные сценарии |
| UI automation / Playwright | Впереди | Создать поддерживаемые UI-тесты |
| CI | Впереди | Запускать тесты автоматически и разбирать ошибки |
| SQL | Впереди | Проверять данные запросами |
| Технический английский | Сквозная практика | Объяснять код, тест-дизайн и решения на английском |
| Портфолио / интервью | Постепенно | Показывать самостоятельные работы и обсуждать компромиссы |

## Корректировка практики с 2026-10-11

- Ориентир нагрузки: **3–5 часов в неделю**, без увеличения ради компенсации проблем с запоминанием.
- Вместо серий почти одинаковых задач — знакомые Python/pytest-инструменты в разных постановках, с акцентом на самостоятельный выбор подхода.
- Короткие вопросы на воспроизведение знаний и интервальное повторение через несколько дней.
- Отдельно оценивать корректность решения и степень самостоятельности (без помощи / после подсказки / после разбора).
- В отчётах разделять кодирование, инженерные активности и организационные потери времени; не смешивать их в одну метрику практики.

## Контекст NZ-2028 (восстановлено из плана 2026-09-26)

**Пять направлений программы:** SDET, English, Career, Money, Immigration. Этот репозиторий покрывает преимущественно SDET и часть English/Career. Для Money/Immigration здесь фиксируется только общий статус направления, **без личных сумм, семейных обстоятельств, визовых документов и прогнозов**. Подготовка к переезду требует отдельно проверить трудоустройство, актуальный визовый маршрут, финансовую устойчивость и сценарий неудачи; это не критерии PASS для Python.

**Исходные ориентиры, не обязательные дедлайны:** оценка готовности к рынку весной 2027, активный поиск летом 2027, желательное окно оффера — осень 2027 — начало 2028. Подтверждать готовность через реальные навыки, резюме, английский и интервью, не по календарю.

**Историческая учебная последовательность:** Python Core до ноября 2026, затем pytest/API/UI и иные инженерные навыки. Фактически pytest начали изучать параллельно раньше, сохранив Python Core. Не делать вид, что первоначальный учебный график был выполнен дословно.

**Контроль самостоятельности:** первоначальная идея Python Gate около 29.11.2026 — новая задача за 60–90 минут без AI, разбор и защита. В текущем состоянии контрольная точка 30.11: она диагностическая, а не автоматически открывающая новый уровень.

**Отчётность:** NZ DAILY / NZ WEEKLY по явному запросу, с реальными свидетельствами и без автоматических напоминаний; не превращать отчётность в дополнительную учебную нагрузку.

## Принципы перехода

- Не добавлять новый инструмент только ради «широты стека».
- Следующий этап открывать после проверки навыков на новой задаче без готового шаблона.
- Намеренно падающий тест, который выявляет нарушение контракта, не считать ошибкой тестирования.
- Отдельно различать учебный прогресс, готовность к интервью и реальный опыт SDET.

Распределение тем и критерии корректируются по результатам практики; изменения фиксируются в `DECISIONS.md`.
