## 2026-10-12 — Task 19: PASS (защита в чате)

- **Контракт:** [Task 19](week03/documentation/task_19.md). **Решение:** [PR #17](https://github.com/xoxacc-ribinja/nz_sdet/pull/17), коммит `9bbefd56` в ветке `task-19` на момент проверки. PR на момент записи **открыт, не слит в main**.

Уточнены различия `==` / `is not`, `isinstance(value, int)` / `type(value) is int`, а также факт, что `bool` — подкласс `int` и сравним с числами без исключения.
